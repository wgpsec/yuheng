# 玉衡下一阶段产品路线与实施规范

状态：P0/P1 主要切片已实施，数据完整性收口待最终审计

## 产品原则

对话是入口，任务和资料是沉淀结果，Agent 是执行者。借鉴 Codex 的可观察、可恢复执行，借鉴 Notion 的低摩擦结构化编辑；不引入云同步、多人协作或完整 Notion 数据库体系。

## 优先级

### P0：巩固基础

- 会话生命周期：分支、从指定消息继续、运行详情、失败重试和恢复。
- Agent 可观察性：工具调用、审批、耗时、错误和上下文使用量。
- 数据完整性：备份恢复、迁移版本和异常退出恢复。

### P1：核心工作流

1. 全局命令面板：`Cmd/Ctrl + K` 打开；搜索会话、消息、任务和看板，并提供新建会话、打开任务等快捷动作。
2. 会话与任务双向关联：消息可创建任务，任务显示来源会话并可跳回；Agent 任务操作在时间线中保持结构化回执。
3. 任务多视图：看板、列表、日历和保存筛选。
4. 块编辑器巩固：撤销/重做、块级移动、稳定粘贴和编辑状态。

### P2：执行体验

- 任务操作预览、批量变更确认和细粒度取消。
- 任务模板、快速捕获和菜单栏快捷新建。

## 本轮实施范围

### Slice 1：全局命令面板

- 复用现有 `search.query` 和搜索结果模型；不新增搜索服务或数据库表。
- `Cmd/Ctrl + K`、侧栏搜索按钮均打开同一面板。
- 空查询提供“新建会话”“打开任务”动作；结果支持键盘上下选择、回车执行、Escape 关闭。

### Slice 2：会话与任务关联

- 复用 `tasks.source_conversation_id`，不新增消息级外键或数据库实体。
- 用户消息提供“转为任务”操作，以消息内容生成任务标题和详情，并绑定当前会话。
- 任务详情继续显示来源会话，点击后回到该会话；已有 Agent 创建任务的“打开任务”回执保持不变。
- 创建后切换到任务看板并打开新任务，失败不改变当前会话。

### Slice 3：任务多视图

- 在现有任务页提供看板、列表和日历三种视图，切换不改变任务存储或编辑入口。
- 列表视图复用当前搜索/筛选结果，支持直接修改任务类型；日历视图按已有截止日期展示任务。
- 当前搜索与筛选条件可保存到本机偏好并在后续打开任务页时应用，不新增数据库实体或同步协议。

### Slice 4：块编辑器巩固

- 继续复用 Tiptap 的编辑历史，提供撤销/重做按钮并反映当前是否可用。
- 块级新增、删除、拖拽移动、Slash 命令、Markdown 粘贴和附件能力保持不变。
- 编辑器显示轻量编辑状态反馈；任务父级的自动保存节奏和持久化字段不变。

### P0 Slice 1：会话分支

- 可从任意用户消息创建独立会话分支，复制该消息之前（含该消息）的历史与现有 Provider/Profile/项目归属。
- 分支使用全新会话和消息身份，原会话保持不变；分支可继续正常发送消息、重命名、归档和删除。
- 继续复用现有会话表、消息表和 IPC，不新增持久化实体。

### P0 Slice 2：运行记录摘要

- 会话时间线提供可折叠的历史运行记录，复用已有运行快照展示状态、时间、耗时、输入/输出 token 和错误摘要。
- 不改变工具活动明细、实时事件、审批流程或运行持久化结构。

### P0 Slice 3：完整备份密钥与恢复校验

- 完整 `.yuheng` 备份可包含由用户明确授权导出的 Provider API Key；会话备份、日志和运行事件仍不包含密钥。
- 恢复解析 `data/provider-keys.json`，过滤非法身份和超长值，成功导入后通过现有 SecretStore 写回本机可移植存储。
- 继续使用现有 manifest 哈希、路径和大小校验；不新增数据库实体或 Worker 协议。
- Pi session 恢复使用临时文件写入后原子重命名；SQLite 记录当前 schema `user_version`，为后续迁移提供单一版本标记。
- 恢复受控附件和运行截图时同步重映射托管 URL；导出期间持有进程内运行准入门禁，避免快照与文件跨时点不一致。

## 非目标

- 本轮不实现云同步、协作、权限、完整 Notion 数据库和日历服务同步。
- 不改变 Pi runtime、Provider 协议、任务表结构或会话消息持久化格式。

## 验收矩阵

- macOS `Cmd + K`、Windows/Linux `Ctrl + K` 均能打开命令面板；输入查询仍走现有搜索结果。
- 空查询动作可创建会话、打开任务；键盘导航和 Escape 可用。
- 从用户消息创建任务后，任务包含来源会话且可从任务详情返回原会话。
- Agent 创建任务的时间线入口和现有任务编辑流程不回归。
- 列表视图可打开任务并修改状态；日历视图按截止日期定位任务，未设置截止日期的任务不会被虚构日期。
- 已保存筛选在重启后仍可应用，保存数量有界且不影响任务数据。
- 块编辑器可使用撤销/重做，块拖拽和 Markdown 粘贴行为保持可用；编辑状态反馈不改变自动保存结果。
- 从用户消息创建分支后，原会话不变，新会话只包含截断点之前的历史且消息身份独立。
- 会话存在多次运行时可展开查看每次运行状态和用量；错误摘要只作为展示，不改变重试/恢复判断。
- 完整备份可 round-trip 明确提供的 Provider API Key；原始 `secrets.json` 内容和 workspace 文件不会被盲目打包。
- session 文件恢复失败只标记上下文不可用并清理临时文件，不留下半写入目标文件；schema marker 可在重启后读取。
- 搜索、任务、会话和设置页面既有行为保持不变。
