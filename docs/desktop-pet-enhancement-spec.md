# 玉衡桌面 Pet 增强 Spec

状态：Slice 1、Slice 2、Slice 3、Slice 4、Slice 6A、Slice 8、Slice 9、Slice 10、Slice 11、Slice 12 已完成
版本：2026-08-31

## 目标

在不引入 Python/PySide6、不中断现有 Electron 主窗口和 Codex Pet 皮肤兼容的前提下，增强玉衡桌面 Pet 的状态表达、资源占用和可控性。

## 设计约束

- Pet 继续使用独立的 Electron `BrowserWindow`，渲染层继续使用 React。
- Codex Pet v1/v2 的 `pet.json + spritesheet.webp` 格式保持兼容。
- Pet 配置写入现有 `AppStore`，通过 preload 暴露最小化 IPC，不把 Node API 暴露给 renderer。
- 所有新增行为默认可关闭；隐藏窗口时不得持续运行动画定时器、帧推进或无必要的轮询。
- 状态变化必须经过白名单校验；未知状态回退到 `idle`，避免外部事件污染渲染状态。
- 拖拽、点击打开主窗口和现有状态动画不得回归。
- 外部项目的代码和素材不直接复制；仅参考其交互和协议设计。该项目源码虽为 MIT，素材仍需逐项确认授权。

## 状态模型

第一阶段统一为以下状态：

| 状态 | 含义 | 触发来源 | 优先级 |
| --- | --- | --- | ---: |
| `idle` | 空闲待机 | 初始、运行结束、取消 | 10 |
| `thinking` | Agent 正在推理 | 运行接收后、等待工具前 | 20 |
| `working` | 工具或执行过程 | 工具开始、审批等待 | 30 |
| `attention` | 需要用户查看 | 可选的提醒事件 | 40 |
| `error` | 运行失败 | 运行失败、工具错误 | 50 |
| `celebrate` | 成功完成的短暂反馈 | 运行完成 | 60 |

`celebrate` 是一次性状态，默认播放 1400ms 后回到 `idle`。同一状态重复事件不得重置动画计时器；高优先级状态可以抢占低优先级状态，但一次性庆祝动画不被普通空闲事件打断。

## Slice 1：Runtime Foundation

状态：已完成

### 范围

- 扩展共享 Pet 状态类型和状态白名单。
- 将运行事件映射到 `thinking / working / error / celebrate / idle`。
- Pet renderer 在窗口不可见或页面被挂起时停止帧定时器；恢复时从当前状态首帧继续。
- 为动画调度器增加纯函数，便于测试状态切换和暂停行为。

### 验收标准

- 现有 `idle / working / celebrate` 测试继续通过。
- 运行失败显示 `error`，取消运行回到 `idle`。
- Pet 隐藏期间不创建新的动画 timer；显示后恢复且不产生快速补帧。
- Codex 皮肤仍按原有行号和帧时长播放。

## Slice 2：Pet Controls

状态：已完成

### 范围

- `DesktopPetConfig` 增加 `locked`、`opacity`、`alwaysOnTop` 三个字段。
- 设置页增加位置锁定、不透明度、置顶开关。
- 锁定只禁止拖拽，不影响点击打开主窗口或状态动画。
- 增加 Pet 右键控制入口：打开玉衡、显示/隐藏 Pet、打开设置、锁定位置、置顶开关、退出桌面 Pet。
- 配置变更实时同步到独立 Pet 窗口并持久化。

### 验收标准

- 配置重启后保持；旧配置缺少字段时使用安全默认值。
- 不透明度限制在 0.2–1.0，窗口不会变成完全不可见。
- 关闭置顶后窗口不再调用浮动层级；开启后恢复浮动层级。
- 锁定时拖拽 IPC 被忽略，点击仍可打开主窗口。
- 右键菜单不会遮挡 Pet，菜单关闭后不会残留窗口或监听器。

## Slice 3：Skin Runtime

状态：已完成

### 范围

- 将 Codex 皮肤的状态行号、帧数和帧时长改为 manifest 可选配置，同时兼容现有默认值。
- 皮肤资源只在 Pet 窗口可见时推进帧计时器；隐藏或恢复时从当前状态首帧继续。

### 验收标准

- 自定义状态动画的帧数和帧时长按 manifest 生效。
- 缺少或不合法的动画覆盖配置时回退到玉衡默认动画。

## Slice 4：State Coordination

状态：已完成

### 范围

- 主进程通过 `PetStateCoordinator` 汇总所有会话的运行事件。
- 并发运行按状态优先级选择可见状态，单个会话的事件不会覆盖其他会话正在执行的工作。
- 完成、失败和取消事件建立终态屏障，忽略同一 run 的迟到事件。
- `celebrate` 和 `error` 使用主进程 TTL 自动恢复；关闭应用时清理状态定时器。

### 验收标准

- 多会话并发时始终显示最高优先级状态。
- 完成或失败后在 TTL 到期前保持反馈，随后恢复到剩余运行状态或 `idle`。
- 终态事件后的迟到 delta、工具和取消事件不会重新唤醒已结束 run。

### Slice 8：可行动反馈

状态：已完成（2026-08-31）

目标是让 Pet 的反馈不仅可见，而且能把用户带到需要处理的位置。

- 将工具内部名称映射为用户可理解的动作描述，未知名称仅展示安全裁剪后的原名称。
- 审批状态点击后打开对应会话并定位待审批区域。
- 失败状态点击后打开对应会话并定位执行记录。
- 完成状态点击后打开对应会话并定位最后回复。
- Pet 只负责导航，不直接执行批准、删除、重试等有副作用或高风险操作。

实现说明：运行事件现在携带经过白名单解析的 `conversation / run / approval` 导航目标；完成事件定位最后回复，失败事件展开并定位运行记录，审批事件聚焦已有审批框。Browser Use、Computer Use、任务和基础文件工具统一显示用户可理解的中文动作描述。

独立 Pet 窗口的 preload 会再次校验反馈和导航目标，并将目标传递给点击/键盘激活入口；sandbox preload 不依赖普通本地模块运行时加载，冷启动和已打开主窗口均保持同一套目标校验。

验收标准：

- 气泡不暴露工具参数、输出和错误原文。
- 已知工具显示稳定、自然的中文动作描述。
- 冷启动和已打开主窗口两种情况下都能精确导航。
- 目标已不存在时只唤醒主窗口，不触发错误或错误跳转。

### Slice 9：防打扰机制

状态：已完成（2026-08-31）

目标是在保留关键信号的同时，避免高频运行事件造成闪烁和噪音。

- 合并短时间内连续的工具事件，避免气泡反复重置。
- 提供“重要状态 / 全部状态 / 隐藏”三档气泡模式。
- 分别控制完成、错误、审批提示和声音。
- 提供专注时段或临时静音。
- 动画遵守 `prefers-reduced-motion`；音效默认关闭。

实现说明：防打扰策略集中在 `resolvePetFeedback`，旧配置默认保持全部气泡、关键提示开启、声音关闭。`working/thinking` 过程反馈在同一运行的 800ms 窗口内合并；独立的完成、错误、审批开关和 30 分钟专注时段写入 `AppStore`，通过独立 Pet preload 同步到窗口。隐藏/静音/减少动态效果时不创建无意义的气泡 timer、音频上下文或精灵帧 timer。

验收标准：

- 高频工具事件不会持续闪烁或延长无关反馈。
- 重要状态模式只显示完成、错误、审批和提醒。
- 所有偏好持久化，旧配置安全回退到默认值。
- 隐藏 Pet 或开启静音后不创建无意义的计时器和音频对象。

### Slice 10：任务和提醒联动

状态：已完成（2026-08-31）

目标是把 Pet 接入玉衡任务数据，但保持提醒轻量和可追踪。

- 到期提醒显示经过裁剪的任务名称。
- 点击提醒中的 Pet 精确打开对应任务卡片。
- Pet 右键菜单增加“今日任务”和“快速记录”。
- 多条提醒按队列展示，不能互相覆盖或丢失。

实现说明：任务提醒使用独立的 Pet 反馈类型和内存队列。任务标题按 Unicode 字符裁剪后展示，队列按提醒时间、任务 ID 稳定排序，同一任务去重并在 12 秒后过期。Pet 点击前会重新校验任务和看板，目标失效时回退到首个任务看板。右键菜单新增“今日任务”和“快速记录”；前者进入今天筛选列表，后者打开新任务编辑器，不会静默创建空任务。

验收标准：

- 任务已删除或看板不存在时安全回退到任务模式。
- 多提醒按稳定顺序展示，并有去重和过期策略。
- 快速记录进入明确的编辑入口，不静默创建空任务。

### Slice 11：皮肤管理增强

状态：已完成（2026-08-31）

目标是让用户能在设置页判断一套皮肤是否完整、兼容和适合使用。

- 预览每个 Pet 状态的实际动画。
- 校验画布尺寸、空白帧、帧率、缺失状态和 manifest 字段。
- 显示状态回退关系和兼容性报告。
- 支持导入、删除和在 Finder 中定位皮肤。
- 保持 Codex Pet v1/v2 向后兼容。

实现说明：设置页通过独立 catalog 展示有效和异常皮肤；主进程解码 WebP 画布并检查实际尺寸与透明空白帧，按状态列出 manifest 覆盖或玉衡默认回退关系。导入只复制经过校验的 `pet.json` 与精灵表到受管理目录，删除活动皮肤会被拒绝，Finder 定位和刷新均通过主窗口受控 IPC 完成。运行时 `pet:list` 仅返回可用皮肤，诊断失败不会替换当前配置。

验收标准：

- 校验失败不会影响当前正在使用的皮肤。
- 删除当前皮肤前必须明确切换到安全默认皮肤。
- 报告使用可行动的用户语言，不直接暴露解析堆栈。

### Slice 12：自然桌面行为

状态：已完成（2026-08-31）

目标是改善 Pet 在多屏桌面上的位置感，同时避免持续运动打扰工作。

- 按显示器记忆位置，并在显示器变化后恢复到可见区域。
- 支持屏幕边缘吸附。
- 提供可选的轻微惯性和边界回弹，默认关闭。
- 随机空闲动画需要限频，并在窗口隐藏时完全暂停。
- 全屏、演示或屏幕共享时自动隐藏。
- 不优先实现持续走动或弹弓玩法。

实现说明：Pet 位置文件升级为按 Electron display id 保存的多屏位置映射，同时兼容旧版单坐标文件；显示器增删或工作区变化时会将位置恢复到当前可见区域。设置页提供边缘吸附、轻微惯性和边界回弹开关，后三者默认关闭，锁定位置时不触发拖动和运动。主窗口进入全屏时自动隐藏 Pet，离开全屏且 Pet 总开关仍开启时恢复；窗口隐藏、关闭或退出应用时清理惯性和动画定时器。空闲精灵每轮结束增加 1.2–3.2 秒的随机停顿，并遵守减少动态效果偏好。

验收标准：

- 拔掉外接显示器后 Pet 不会停留在屏幕外。
- 锁定位置时吸附、惯性和回弹均不改变位置。
- 减少动态效果开启时禁用非必要运动。
- 自动隐藏不会改变用户的 Pet 总开关。

## 非目标

- 不把 `dsh-pet-indesktop` 作为 npm 或 Python 运行时依赖。
- 不在本轮复制其 WebM 角色素材或音频素材。
- 不改变 Browser Use、Computer Use、笔记和任务模式的业务逻辑。
- 不实现外部 Agent 状态桥接、远程状态输入或任意脚本入口。
- 不主动识别屏幕内容。
- 不在 Pet 上直接执行高风险操作。
