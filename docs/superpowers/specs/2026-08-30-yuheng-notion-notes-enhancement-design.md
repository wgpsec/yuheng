# 玉衡 Notion 风格笔记增强设计

状态：已实施，待产品验收

目标版本：`0.3.x`

## 1. 背景

玉衡笔记已经支持页面树、子页面、图标、Cover、Markdown 块编辑、拖拽排序、附件、内部链接、反向链接和可审查的 AI 修改。下一阶段优先补齐三类高频体验：更完整的内容块、新建页面模板，以及收藏/最近访问/快速打开。

本设计不引入完整 Notion Database、云同步、多人协作或新的通用内容模型。

## 2. 产品原则

- Markdown 继续作为笔记正文的权威表示，已有笔记无需迁移即可打开和保存。
- 只有能够稳定导入、编辑、导出和备份恢复的块类型进入第一期。
- 页面模板只负责创建时填充初始标题、正文和可选图标；创建后页面与模板没有持续绑定。
- 收藏和最近访问属于本地导航元数据，不改变页面层级、正文或搜索相关性。
- Renderer 只通过现有 Desktop Bridge 读写；SQLite 和文件系统继续由 Electron 主进程持有。

## 3. Slice 1：块编辑器增强

### 3.1 范围

在现有 `/` 菜单和块操作菜单中补充：

- 分隔线：使用标准 Markdown `---`。
- 折叠块：使用 Tiptap 官方 fenced directive `:::details` 保存，编辑器中以可展开块呈现；摘要和正文继续由普通文本/Markdown 块组成。
- Callout：使用同类 fenced directive `:::callout {kind="info"}` 保存，支持信息、提示、警告三种视觉类型。
- 代码块增强：保留 fenced code block，支持语言标记和一键复制；不引入代码执行。
- 表格：使用 GFM pipe table，支持插入默认 `3 x 3` 表格并继续编辑单元格。
- “转换为”：现有块菜单统一提供正文、标题、列表、任务清单、引用、代码块、Callout 等转换入口；不兼容的复合块采用插入而不是破坏性转换。
- 块复制：复制当前顶层块并插入到其后。
- 移动到其他页面：选择目标页面后，将当前块追加到目标页末尾；目标保存成功后才从来源页删除。目标或来源保存失败时不得静默丢失内容。

### 3.2 兼容边界

- 编辑器不识别的 HTML、GFM 或旧 Markdown 保持为可读内容，不在加载时静默删除。
- 任务详情继续复用基础块能力，但页面移动和页面专属链接只在笔记编辑器启用。
- 页面块、附件和内部链接的既有序列化保持不变。
- 第一版不实现列布局、公式、数据库块、同步块、目录块和嵌入式网页。

### 3.3 验收

- 新块经过“输入 → 保存 → 关闭页面 → 重开”后内容和类型不变。
- 既有 Markdown 打开并保存不会被无关改写。
- `/` 菜单可键盘选择新增块；块菜单可复制和移动。
- 移动块失败时来源仍保留；成功时目标只新增一次、来源只删除一次。
- 代码复制不触发编辑，表格可用键盘在单元格间导航。

## 4. Slice 2：页面模板

### 4.1 范围

新建顶级页面和子页面时提供轻量模板选择器：

- 空白页面
- 会议记录
- 项目计划
- 读书笔记
- 每周复盘
- 技术文档

模板定义为 Renderer 内置的稳定清单，包含模板 ID、名称、说明、图标、默认标题和 Markdown 正文。空白页保持现有一键创建路径；用户选择其他模板后再创建页面。

第一期不新增模板表，不支持模板市场、远程模板、变量脚本或模板更新后批量修改既有页面。

### 4.2 验收

- 顶级页面和子页面都能从模板创建，父子关系正确。
- 模板正文由现有编辑器直接打开并可独立修改。
- 连续点击或创建失败不会生成重复页面。
- 取消模板选择不创建页面；空白页仍可快速创建。
- 完整备份无需新增特殊处理，模板创建出的页面按普通笔记恢复。

## 5. Slice 3：收藏、最近访问和快速导航

### 5.1 数据模型

在现有 `notes` 表增加两个本地字段：

- `favorite INTEGER NOT NULL DEFAULT 0`
- `last_opened_at TEXT NULL`

通过现有启动迁移使用 `ALTER TABLE` 补列，不新增表。备份快照同步携带字段；旧备份缺失字段时按未收藏、未访问导入。

### 5.2 行为

- 页面菜单支持收藏和取消收藏。
- 侧栏在页面树上方展示“收藏”和“最近访问”两个可折叠分组。
- 收藏按最近访问时间、页面更新时间排序；最近访问去重并限制为 10 项。
- 用户通过侧栏、路径、内部链接、搜索或恢复标签页真正打开页面时更新 `last_opened_at`。
- 后台 `list/get`、备份、反向链接扫描和搜索索引读取不得更新访问时间。
- 已归档页面不出现在收藏和最近访问分组；恢复归档后保留原收藏信息。
- 快速打开复用现有全局搜索和 `Cmd + K`，增加收藏/最近页面候选，不新增独立搜索引擎。

### 5.3 验收

- 收藏状态重启后保留，收藏不改变页面树位置。
- 打开页面会更新最近访问，后台刷新不会更新。
- 归档页面从两个快捷分组隐藏，恢复后行为一致。
- 从收藏、最近访问和快速搜索打开页面时，标签页、路径和页面树选中状态一致。
- 旧数据库和旧备份可无损升级；新备份恢复后收藏状态保留。

## 6. 实施顺序

1. Slice 1：先补纯函数和序列化回归，再接入编辑器交互。
2. Slice 2：先定义模板目录和创建输入，再接入页面创建弹层。
3. Slice 3：先迁移 Store/Bridge/备份合同，再接入侧栏和快速导航。

每个 Slice 完成针对性行为测试、类型检查和构建后再进入下一项。

## 7. 测试策略

- 块类型测试覆盖 Markdown 往返、复制和跨页面移动的原子行为，不扫描 CSS 或固定文案。
- 模板测试覆盖模板目录、创建 payload、父子关系和重复提交。
- 收藏/最近访问测试覆盖 SQLite 迁移、显式 touch、归档过滤和备份 round-trip。
- UI 只为有行为价值的菜单、创建和导航流程补测试；样式细节通过构建后人工检查。

发布前门禁：

```bash
npm test
npm run typecheck
npm run build
git diff --check
```

## 8. 非目标

- 完整 Notion Database、Relation、Rollup、Formula。
- 评论、分享、多人实时协作、云同步。
- 自定义模板持久化和模板市场。
- 可执行代码块、Mermaid、第三方网页嵌入。
- 跨页面块引用和同步块。

### 侧栏与编辑反馈收口（2026-08-31）

本轮只调整现有笔记导航和编辑反馈，不新增持久化实体、IPC、页面状态或内容模型。按以下 tracer bullet 顺序逐项完成，每项先验证公开行为，再进入下一项：

1. 页面条目悬停时显示“新建子页面”和“更多”操作；默认隐藏，键盘聚焦时同样可见。点击新建只创建一个直接子页面，点击标题仍只打开页面。
2. 页面层级使用统一缩进；分支引导线默认弱化，仅当前分支悬停、聚焦或拖拽时增强，不改变树顺序。
3. 拖拽明确区分插入前、成为子页面、插入后；三种反馈使用稳定放置区域，非法目标继续由现有 `resolveNoteDrop()` 拒绝。
4. 收藏、最近访问、库使用同一整行展开交互；展开状态沿用前端缓存，过渡尊重 `prefers-reduced-motion`。
5. 页面行高、图标槽位和标题基线统一；默认显示页面图标，有子页面时悬停将同一槽位替换为展开箭头。
6. 新建页面后立即打开并聚焦标题；保存状态继续使用保存中、已保存、保存失败，失败保留草稿并提供现有重试能力。
7. 库列表末尾提供低噪音“新页面”入口，直接创建一个空白根页面；提交中禁止重复创建。

行为测试聚焦创建身份、父子关系、非法拖拽、展开偏好、标题聚焦请求和重复提交；悬停透明度、像素间距、颜色及过渡时长通过构建和人工视觉检查，不增加扫描 CSS 或源码字符串的脆弱测试。
