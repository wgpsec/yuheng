# 任务看板默认删除与任务迁移设计

状态：已按 TDD 实施，待最终审计

目标版本：`0.4.x`

## 1. 背景

当前任务模块把 `default` 看板硬编码为不可删除。随着用户创建多个真实看板，这会留下无法清理的空看板，也无法表达用户希望将另一看板作为默认入口的意图。删除看板还必须避免丢失其中的任务和自定义列。

## 2. 目标

- 允许删除当前默认看板；有任务时必须由调用方明确提供一个不同的替代看板，空看板可直接删除。
- 删除看板中的任务全部迁移到替代看板，不删除任务内容、提醒、来源会话或其他业务字段。
- 迁移目标成为新的默认看板；删除默认空看板且未选择目标时，由删除后按位置最早的剩余看板接替默认入口；后续省略 `boardId` 的任务 API 使用该看板。
- 删除看板及任务迁移、默认看板更新、位置整理在同一个 SQLite 事务中完成，任一步失败都回滚。
- 不新增数据库表、业务字段、持久化状态机或新 endpoint；默认看板 ID 复用 `app_settings` 的 `default_task_board_id`。

## 3. 不变边界

- 不改变任务、任务类型和看板的现有数据结构。
- 不复制任务，不重建任务 ID；只更新原任务的 `board_id`、目标类型 `status`、目标列 `position` 和已有更新时间语义。
- 不影响看板重命名、排序、单任务跨看板移动或备份格式。
- 旧数据库没有默认设置时继续使用 `default`（若该看板存在）；读取到失效设置时回退到当前最早看板，并保持可用。

## 4. 公开行为

### 4.1 删除调用

`deleteTaskBoard(boardId, replacementBoardId)` 要求：

1. `boardId` 为非空字符串；`replacementBoardId` 可为空，但非空时不能与源看板相同。
2. 源看板存在；非空替代 ID 对应的看板必须存在。
3. 数据库至少保留一个看板；删除最后一个看板失败。
4. 源看板有任务时必须明确选择替代看板，不能把任务丢弃；空看板不需要迁移目标。

删除普通或默认看板都遵循同一规则。默认看板常量只用于旧数据兼容，不再作为不可删除的业务限制。

### 4.2 任务类型映射

- 先按源任务类型名称与替代看板类型名称精确匹配。
- 同名类型重复时选择目标 `position` 最小者。
- 无匹配时使用替代看板中 `position` 最小的类型。
- 替代看板没有任何类型时整个操作失败并回滚。
- 每个目标类型的迁移任务追加到该列已有任务之后，位置按稳定顺序重新编号，不覆盖已有任务。

### 4.3 默认看板解析

- `app_settings` 以 `default_task_board_id` 保存当前默认 ID。
- 删除操作在同一事务内将该设置写为替代看板 ID；删除默认空看板且未提供替代 ID 时，选择删除后按位置最早的剩余看板。
- 所有省略 `boardId` 的 Store/Repository 任务读写入口动态解析该设置；显式传入的 ID 行为不变。
- 应用启动或设置失效时，回退到 `default`，再回退到按位置最早的看板；不创建额外看板。

## 5. IPC 与前端

- 保持 `tasks:boards:delete` endpoint 不变，仅将参数扩展为 `(boardId, replacementBoardId)`，preload 和 Desktop Bridge 类型同步更新。
- Sidebar 删除任意看板都打开统一确认交互；选择替代看板时展示迁移说明，留空表示仅尝试删除空看板。有任务时由后端拒绝无目标请求；仅剩一个看板时仍不能删除。
- 删除成功后刷新看板列表，并切换到新的默认/替代看板；后端错误显示在现有看板错误区域。
- 不在确认前执行删除，不用浏览器端过滤代替后端事务。

## 6. TDD 验收矩阵

| 行为 | 验收 |
| --- | --- |
| 普通看板删除 | 任务迁移到替代看板，原任务 ID 和内容保留 |
| 默认看板删除 | 替代看板成为默认看板，省略 `boardId` 的创建/列表使用替代看板 |
| 类型映射 | 同名映射；无同名时进入目标第一列；目标已有任务顺序不被覆盖 |
| 删除最后看板 | 失败且所有数据不变 |
| 删除空看板 | 无需迁移目标即可删除；删除默认空看板后剩余看板成为默认 |
| 替代看板无效/相同 | 失败且所有数据不变 |
| 事务失败 | 源看板、任务、默认设置均保持删除前状态 |
| 重启 | 默认看板设置持久化，重新打开 Store 后行为一致 |
| IPC/前端 | 参数经过校验；空看板可不选迁移目标，有任务时必须选择；删除成功后视图切换 |
