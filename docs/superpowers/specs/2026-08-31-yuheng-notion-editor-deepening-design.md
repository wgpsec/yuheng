# 玉衡 Notion 风格编辑与页面能力深化设计

状态：已按 TDD 实施并完成回归审计

目标版本：`0.3.x`

## 1. 目标

在现有 Markdown 权威正文、页面树、内部链接、自动保存和完整备份能力上，按以下顺序补齐八项高频能力：

1. 多块选择与批量操作。
2. 分类、搜索、最近使用的 `/` 命令菜单。
3. 页面历史与版本恢复。
4. 内部页面侧边预览。
5. 长页面目录。
6. 页面、日期和任务 `@` 提及。
7. 块级悬停与拖拽预览收口。
8. 可选的轻量页面属性。

每项作为独立纵向 Slice 完成 RED、GREEN、重构和聚焦回归后，再进入下一项。

## 2. 不变边界

- 笔记正文继续以 Markdown 为权威表示，不迁移为专有块 JSON。
- Renderer 只通过 Desktop Bridge 访问数据；SQLite 和文件系统仍由 Electron 主进程持有。
- 不引入完整 Database、Relation、Rollup、Formula、多人协作、评论或云同步。
- 样式、像素和过渡不新增源码扫描测试；测试验证公开行为、数据往返和可访问交互。
- 现有页面、内部链接、附件、Cover、收藏、最近访问和旧备份保持兼容。

## 3. Slice 1：多块选择与批量操作

- 从页面正文左侧沟槽按住主键拖动，可正向或反向选择连续顶层块；Pointer Capture 保证指针离开沟槽后仍能完成选择。
- 正文内部继续使用原生文本选择，不得被块选择接管；点击块手柄和 `Shift` 点击另一块手柄保留为辅助入口。
- 每个已选块使用 ProseMirror Decoration 独立投影高亮，不直接修改易被编辑器重绘丢失的 DOM class。
- 已选择范围通过固定批量栏提供复制到系统剪贴板、删除和移动到其他页面，并继续支持从块手柄拖拽排序；复制输出 Markdown 且不得修改当前页面，成功和失败均在批量栏即时反馈，文档内生成副本使用独立的“创建副本”命令。
- 长页面靠近可滚动区域上下边缘时自动滚动；速度按帧耗时归一化，避免 120Hz 屏幕加速。
- 批量移动沿用现有目标先提交、来源后删除的原子 Store 操作；失败时来源不得丢失。
- 点击正文、编辑器外部、正文末尾空白或按 `Escape` 清除块选择；块选择与文本格式浮窗互斥。
- 不支持跨页面非连续块集合；第一期只处理同一页面的连续顶层块。

## 4. Slice 2：`/` 命令菜单

- 命令按基础块、列表、内容块、媒体分组显示。
- 输入中文名称、英文 ID 或别名均可过滤；键盘上下选择、回车应用、Escape 关闭。
- 本地记录最近使用的最多 6 个命令；空查询时优先显示最近使用，随后显示完整分组。
- 损坏的本地缓存回退为空，不影响编辑。

## 5. Slice 3：页面历史与版本恢复

- 新增 `note_versions` 本地表，保存页面标题、正文、图标、Cover、轻量属性和创建时间。
- 仅页面可见内容实际变化时记录更新前版本；收藏、访问时间、归档和树移动不制造正文版本。
- 每页最多保留最近 50 个版本；恢复前先保存当前版本，因此恢复操作可以撤销。
- 页面设置打开历史面板，可预览时间与摘要并恢复指定版本。
- 完整备份携带历史；旧备份没有历史时正常导入。

## 6. Slice 4：页面侧边预览

- 正文中的内部页面链接默认打开右侧预览，不替换当前页面。
- 预览显示页面图标、标题和只读 Markdown，并提供“完整打开”和关闭按钮。
- 已归档或不存在的页面给出明确错误；外部链接与附件行为不变。
- 同一时刻只保留一个预览，不新增窗口或标签实体。

## 7. Slice 5：长页面目录

- 从 Markdown 的一级至三级标题生成稳定目录，忽略 fenced code 中的伪标题。
- 有至少两个标题时显示目录入口；点击条目滚动到对应编辑器标题。
- 当前滚动章节可高亮；目录可折叠且不长期占用正文宽度。
- 标题编辑后目录随正文更新，不持久化派生目录。

## 8. Slice 6：`@` 提及

- 输入 `@` 搜索页面、未归档任务以及“今天/明天”日期。
- 页面提及使用现有 `yuheng-note://` 稳定身份；重命名后由编辑器显示当前标题。
- 任务提及使用不可导航到外部网页的 `yuheng-task://` 内部身份，并可打开对应看板任务。
- 日期提及写入可读、稳定的本地日期文本，不引入提醒或日历状态。
- `[[` 页面链接入口继续兼容。

## 9. Slice 7：块级交互收口

- `+` 与手柄只在当前块悬停、聚焦或已选择时显示。
- 拖拽预览使用实际选中块内容，不显示仅包含手柄的黑色系统预览。
- 插入线与正文宽度对齐；减少动态效果偏好下禁用非必要过渡。
- 不改变拖放事务和 Markdown 序列化结果。

## 10. Slice 8：轻量页面属性

- 页面可选增加状态、日期和标签；默认不显示空属性表单。
- 属性保存在现有 Note 聚合的 JSON 列中，不建立 Database 或独立属性实体。
- 标签去空、去重并限制数量和长度；状态为自由短文本；日期为本地 `YYYY-MM-DD`。
- 属性进入自动保存、页面历史和完整备份；旧数据库与旧备份按空属性兼容。

## 11. 验证门禁

每个 Slice 先运行对应聚焦测试。全部完成后运行：

```bash
npm run typecheck
npm test
npm run build
git diff --check
```

构建后的样式与交互通过 macOS 客户端人工验收；不以固定 class、颜色或像素断言替代视觉验收。
